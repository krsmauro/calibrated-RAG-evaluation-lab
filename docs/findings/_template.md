# F-NNN: short title

- **Status:** open | confirmed | refuted | resolved
- **Date:** YYYY-MM-DD
- **Found by:** agent/session name, or user
- **Evidence level:** measured (command and output below) | read from a source (cite it) | hypothesis (not checked)
- **Affects:** step ids (for example 3.1, 4.6) and Design sections

## Finding
What is true, in two to five sentences. Numbers include n and units.

## Evidence
Command run, dataset or run id, the output that matters. For a hypothesis, say what check would settle it.

## Consequence
What changes in the plan, design or code. If a step changed, name it and note the deviation in that step's Done line.

## Resolution
Filled in when the status becomes resolved: what was done and where.
